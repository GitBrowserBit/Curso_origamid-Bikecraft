# 🚴 Bikecraft

Projeto desenvolvido a partir do curso da Origamid com foco em **HTML e CSS moderno**, priorizando **responsividade, acessibilidade e boas práticas de front-end**.

## 🚀 Tecnologias utilizadas

* HTML5
* CSS3
* Flexbox & Grid Layout
* Responsividade
* Acessibilidade (ARIA + semântica)

---

## 🎯 Objetivo

Este projeto foi desenvolvido com o objetivo de:

* Praticar estruturação semântica com HTML
* Criar layouts modernos com CSS
* Aplicar conceitos de responsividade
* Implementar boas práticas de acessibilidade
* Simular um projeto real de interface

---

## ✨ Diferenciais

* Layout totalmente responsivo 📱
* Uso de HTML semântico ♿
* Organização de código escalável
* Componentização visual (reutilização de estilos)
* Design baseado em UI/UX

---

## 📚 Aprendizados

Durante o desenvolvimento, foram aplicados conceitos importantes como:

* Estruturação de páginas com foco em SEO
* Uso de Flexbox e Grid para layout
* Separação e organização de estilos
* Construção de interfaces reutilizáveis
* Acessibilidade na web
